**Description:**

Orbit is a unified gaming overlay, similar to a game bar, for many uses. The goal is to unify the tools present currently into one, easy to use overlay.

---

**Features:**

- Drop down bar (Ctrl + Alt + O)
- Linux & Windows support
- Performance Widget

**Planned Features:**

- Video Clipping
- Game Screenshots (Organized, any game)
- Discord Rich Presence
- Widget Marketplace
- Music App Control Widget
